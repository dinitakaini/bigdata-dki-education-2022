# Data Dictionary

## Informasi Dataset

Dataset yang digunakan berjudul **Jumlah Sekolah, Guru, dan Murid Menurut Jenis Sekolah Tahun 2022** dengan cakupan wilayah DKI Jakarta. Dataset terdiri dari 77 baris dan 8 kolom.

## Penjelasan Kolom

| No | Nama Kolom | Tipe Data | Keterangan |
|---|---|---|---|
| 1 | periode_data | Integer | Menunjukkan periode data yang digunakan, yaitu tahun 2022. |
| 2 | tahun | Integer | Menunjukkan tahun pencatatan data, yaitu 2022. |
| 3 | wilayah | String | Menunjukkan wilayah administrasi di DKI Jakarta. |
| 4 | jenjang_sekolah | String | Menunjukkan jenjang atau jenis pendidikan, seperti PAUD, SD, SMP, SMA, SMK, SLB, dan PKBM. |
| 5 | status_sekolah | String | Menunjukkan status sekolah, yaitu Negeri atau Swasta. |
| 6 | jumlah_sekolah | Integer | Menunjukkan jumlah sekolah pada setiap kelompok data. |
| 7 | jumlah_peserta_didik | Integer | Menunjukkan jumlah peserta didik pada setiap kelompok data. |
| 8 | jumlah_guru | Integer | Menunjukkan jumlah guru pada setiap kelompok data. |

## Keterangan Dataset

- Jumlah baris: 77
- Jumlah kolom: 8
- Tahun data: 2022
- Wilayah: DKI Jakarta
- Format data mentah: XLSX
- Format data hasil pengolahan: XLSX

## Catatan

Kolom `periode_data` dan `tahun` sama-sama memiliki nilai 2022 pada dataset yang digunakan. Kedua kolom tetap dipertahankan karena merupakan bagian dari struktur data sumber.
