# Analisis Data Pendidikan DKI Jakarta Tahun 2022

## Deskripsi Proyek

Proyek ini bertujuan untuk menganalisis jumlah sekolah, guru, dan murid berdasarkan jenis sekolah di Provinsi DKI Jakarta pada tahun 2022.

Analisis dilakukan untuk melihat gambaran persebaran jumlah sekolah, guru, dan peserta didik serta menghitung rasio murid terhadap guru dan sekolah.

## Dataset

Dataset yang digunakan adalah:

**Data Jumlah Sekolah, Guru, dan Murid Menurut Jenis Sekolah di Provinsi DKI Jakarta Tahun 2022**

Sumber:
- Data.go.id
- Satu Data Jakarta

## Tujuan Analisis

1. Mengetahui gambaran jumlah sekolah, guru, dan peserta didik berdasarkan jenis sekolah.
2. Menganalisis rasio murid terhadap guru (STR).
3. Menganalisis rasio murid terhadap sekolah (SSR).
4. Mengelompokkan jenis sekolah berdasarkan kondisi jumlah sekolah, guru, dan peserta didik menggunakan metode clustering.
